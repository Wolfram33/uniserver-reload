Command line parameters

The servers can be controlled directly from the command line by running UniController with a command parameter: start, stop and restart Apache and MySQL/MariaDB individually or together, and query server status. UniController executes the command, reports the result on the console and terminates with an exit code, making all commands fully scriptable (batch files, PowerShell, build and deployment scripts, CI pipelines).

This page covers command parameters supported by UniController.

Parameters

UniController accepts one of the following parameters:

Parameter Description
start_apache Starts Apache server
stop_apache Stops Apache server
restart_apache Restarts Apache server (starts it if it was stopped)
start_mysql Starts MySQL/MariaDB server
stop_mysql Stops MySQL/MariaDB server
restart_mysql Restarts MySQL/MariaDB server (starts it if it was stopped)
start_both Starts Apache and MySQL/MariaDB servers
stop_both Stops Apache and MySQL/MariaDB servers
restart_both Restarts Apache and MySQL/MariaDB servers
status Prints the state of both servers (running / stopped / not installed) and encodes it in the exit code
help Prints usage, all commands and the exit codes
pc_win_start Automatic start-up. For details, see note 2.

All commands are also accepted in the common double-dash spelling, for example --restart-apache for restart_apache. The _both commands are additionally accepted as start_all, stop_all and restart_all.

Note 1: Before starting UniController with a parameter, first ensure servers have been configured and function correctly. In other words, start UniController normally and test the servers.
Note 2: Except for pc_win_start, UniController is closed after executing the command line parameter. Detailed use of pc_win_start is covered in section PC-Win start-up on the Extra Utilities page.
Note 3: In command line mode no dialog windows are shown; warnings are printed to the console instead, hence commands never block waiting for a click and are safe to run from unattended scripts and remote sessions.

Exit codes

Every command returns an exit code so scripts can detect success or failure:

Command Exit code Meaning
Actions (start/stop/restart) 0 Success – the server(s) reached the requested state
  1 Failure – a server did not reach the requested state (or is not installed)
  2 Unknown command line parameter
status 0 All servers running
  +1 Apache not running (bit mask)
  +2 MySQL/MariaDB not running (bit mask)

For status the exit code is a bit mask: 0 = both running, 1 = only Apache down, 2 = only MySQL/MariaDB down, 3 = both down.

Important – waiting for the exit code: UniController is a GUI application. An interactive command prompt does not wait for GUI programs, so the exit code is not available directly. Inside a batch file cmd waits automatically. From an interactive shell or PowerShell use:

cmd (interactive) 
start /wait UniController.exe restart_apache
echo %ERRORLEVEL%
  PowerShell 
$p = Start-Process .\UniController.exe restart_apache -PassThru
$p.WaitForExit()
$p.ExitCode

Do not use Start-Process -Wait in PowerShell: it waits for the started process and all its child processes. A start_* command launches the server as a child process, so -Wait would block until the server itself is stopped. $p.WaitForExit() waits for UniController only.

Console output: text output (for example from status or help) is written to the console the command was started from and can be redirected to a file as usual (UniController.exe status > state.txt). When UniController is started by double click there is no console; the exit code still carries the result.

Script examples

Create the following batch files and place them in folder UniServerZ.

Run each file pair. For example, start_apache.bat/stop_apache.bat demonstrates starting and stopping the Apache server.

start_apache.bat 
UniController.exe start_apache
pause
  start_mysql.bat 
UniController.exe start_mysql
pause
  start_both.bat 
UniController.exe start_both
pause
stop_apache.bat 
UniController.exe stop_apache
pause
  stop_mysql.bat 
UniController.exe stop_mysql
pause
  stop_both.bat 
UniController.exe stop_both
pause

A deployment-style example – restart Apache after changing its configuration and fail the script if the restart failed:

deploy.bat 
UniController.exe restart_apache
if errorlevel 1 (
  echo Apache restart FAILED
  exit /b 1
)
echo Apache restarted
  deploy.ps1 
$p = Start-Process .\UniController.exe restart_apache `
     -PassThru
$p.WaitForExit()
if ($p.ExitCode -ne 0) {
  throw "Apache restart failed ($($p.ExitCode))"
}
"Apache restarted"

Note:
If the batch files are located outside of folder UniServerZ (for example, folder UniServerZ and batch files are located at the top-level of C drive), adjust path to UniController.exe in each batch file (C:\UniServerZ\UniController.exe start_apache). Relative paths work as well (UniServerZ\UniController.exe start_apache).
